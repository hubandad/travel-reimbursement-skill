# 验收案例（均为虚构）

这些案例用于验证行为，不是任何人的实际报销记录。除特别注明，使用本技能的150/100元日标准；住宿等其他费用不在案例范围内。

| 场景 | 输入 | 应有结果 |
| --- | --- | --- |
| 普通员工同日往返 | 去程128元、返程145元、差额退票费3元；确认普通员工 | 票据276元；补助1×100＝100元；合计376元；3张费用发票 |
| 部门经理同日往返 | 同上；确认部门经理 | 票据276元；补助1×150＝150元；合计426元，不能沿用模板的100元 |
| 级别未知 | 同上；没有岗位信息 | 先核对票据276元，询问补助档位；不给出确定的含补助总额 |
| 旧模板与新规则冲突 | 模板说明100元/天；现行规则为经理150元/天 | 经理按150元计算，说明采用更新制度 |
| 跨日经理出差 | 公司确认按自然日含首尾；6月1日至3日 | 3天×150＝450元，不能按2晚或票数算天数 |
| 重复文件 | 同一发票号码的 PDF 与截图各1份，金额128元 | 计128元和1张发票 |
| 票号精度 | 原票号为字符串 `26000000000000000017` | 写回后仍为完整文本，不变成 `26000000000000000000` |
| 开票晚于出行 | 6月8日乘车，6月12日开票；模板采用出行日 | 报销行日期为6月8日，台账保留开票日期 |
| 退票费与退款 | 原票100元，确认退款90元，另有10元退票费发票 | 净支出10元；查明原票、退款、手续费关系，不能报100＋10元或重复列两次10元 |
| 同日多个项目 | 同一经理同日行程分属两个文件夹 | 如同属一次计补出差，当日补助合计150元，不能两份各150元 |
| 两人不同级别 | 一名经理、一名普通员工，均符合条件1天 | 补助分人为150元和100元，合计250元 |
| 残留样例及错误公式 | 模板有旧费用999元，费用类型含 `#REF!`，文字金额只加前两行 | 清除旧样例；修复直接影响本次的引用；两种合计均覆盖本次全部明细；告知修改 |
| 模板保留 | 模板原有隐藏人员表、下拉、A4横向和打印区域 | 保存后仍保留；不公开隐藏人员表，不将真实模板放进技能仓库 |
| 用户已手动修改 | 用户说本次已改好，现在只需总结流程 | 不重新打开并覆盖已修改的报销文件 |
| 页面解析失败 | PDF 无文字或预览缺字 | 切换解析器/查看/OCR；无法核实时列为待确认，不当作零元或漏计 |
| 不同公司制度 | 用户明确其公司经理补助为180元/天 | 使用其现行规则；不强制套用本技能的150元 |
