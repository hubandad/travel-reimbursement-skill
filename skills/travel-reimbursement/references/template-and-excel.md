# 模板映射与 Excel 保留经验

## 常见字段映射

以下为通用映射，实际以用户本次提供的模板为准；没有默认的固定列号。

| 模板字段 | 数据依据 |
| --- | --- |
| 编制单位 | 本次费用归属单位；与票面购买方核对，冲突时询问 |
| 申请人、部门 | 当前用户确认或可靠人员表；不沿用他人样例 |
| 申请日期 | 实际编制或用户指定日期，不冒充出行日期 |
| 日期 | 模板要求的出行日或费用发生日 |
| 事项 | 票面服务、路线、车次及费用性质 |
| 发票号码 | 原始文字，不是电子客票号、订单号或浮点数 |
| 金额 | 票面费用；补助使用天数乘日标准公式 |
| 业务线、费用科目 | 当前人员/活动事实与模板选择项 |
| 备注 | 出差事由；退改签性质；补助级别、天数和标准 |
| 发票张数 | 对应费用发票的实际份数；补助不计票数 |
| 出差天数 | 去重后的实际符合条件天数，不是票数 |
| 展会/会议、合同、研发项目 | 仅有实际证据且需要时填写，不能编造 |
| 费用承担部门、人员 | 实际承担对象，不等同于票面购买方 |

## 工具选择与保存后复核

遵循当前环境的电子表格工具要求。能够处理文件，不等于能无损保留所有 Excel 功能。

- 导入/导出可能丢失 `print_area`、纸张方向、缩放、扩展数据验证、隐藏状态或命名区域。保存后与原模板对照这些功能。
- 类库提示“不支持某种数据验证，保存时会移除”时，不能忽略后继续宣称无损。改用能够保留该功能的工具，或采用严格局部的 OOXML 更新。
- 读取分析用的工具无需同时承担写回；禁止为了方便把整个模板重新设计。
- 读取公式文本与读取缓存值用途不同；确认修改后的公式实际算出结果，并验证旧缓存没有掩盖错误。没有可用计算引擎时如实说明未验证的部分。
- 预览中的科学计数法既可能来自错误类型，也可能是渲染器行为。先检查实际文件里票号是否保持完整文本；不要靠把长整数转成数字来修复显示。

## 仅在需要时采用局部 OOXML 更新

适用于少量费用单元格更新、通用导出工具会破坏既有功能的情况。执行者需具备可靠的 XLSX 处理能力；技能不要求所有任务采用该方式。

1. XLSX 是 ZIP 包。通过 `xl/workbook.xml` 和 `xl/_rels/workbook.xml.rels` 按工作表名称定位部件，不猜 `sheet3.xml`。
2. 保留原始 ZIP 作为基础；只修改获准单元格及其直接依赖的公式/设置。未涉及的工作表、关系、样式、下拉和打印设置应保持不变。
3. 写入共享字符串索引时必须引用正确的共享字符串表。不能直接从另一份工作簿复制索引；可解析成文字，再写为 `inlineStr`。
4. 保留原单元格样式索引。日期底层序列需遵循工作簿1900/1904日期系统；文本票号须明确写成文本，金额须写成数值。
5. 保留 XML 命名空间及兼容扩展声明。整段重序列化可能删除仍被 `mc:Ignorable` 等属性引用的前缀，导致 Excel 修复提示。
6. XML 单元格需按合法行列顺序保存；不要为未变动的空白范围制造额外内容。
7. 不从其他工作簿盲拷样式编号、关系编号或计算链。对受影响公式使用兼容计算引擎重算并核验缓存，或明确标明需重新计算；不能只改公式文本而留下误导性旧值。
8. 重新打开文件并比较包内变更部件。只有目标工作表发生变化，是保留无关部件的证据，但仍需检查目标表内的格式与功能。

对于签名、宏、外部链接或不熟悉的特殊结构，应选用能正确保留这些功能的工具。不要将未知模板改成普通平面表来规避困难。
